# Eredeti 3D karaktermodellek — NEON NEXUS v3.3

A játék `index.html` állománya ezt a három pontos fájlnevet várja ugyanebben a mappában:

- `marin.glb` — Marin Kitagawa
- `makima.glb` — Makima (*Chainsaw Man*)
- `po.glb` — Po (*Kung Fu Panda*)

## Feltöltés

1. Töltsd le a ChatGPT által mellékelt **NEON_NEXUS_v3.3_3D_modellek.zip** csomagot.
2. Csomagold ki. A `models` mappában lesz a három `.glb`.
3. GitHubon nyisd meg ezt a `models` mappát, kattints az **Add file → Upload files** menüre, majd töltsd fel mindhárom `.glb` fájlt.
4. Kattints a **Commit changes** gombra, és frissítsd a játékot `Ctrl + F5`-tel.

A játék átmeneti, alacsony részletességű figurákat használ, amíg a modellfájlok nem érhetők el.
